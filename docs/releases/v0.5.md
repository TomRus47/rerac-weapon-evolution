## Changes since 0.4.2

### Quick Select and controls

- Add a second eight-slot Quick Select ring. Hold Triangle and press R2 to
  switch rings; the last ring is remembered. The pause-menu editor uses R2 too,
  and both rings are saved with the selected save slot.
- Add optional world pause while Quick Select is open. Ring and experimental-mode
  confirmation sounds play immediately even while world simulation is paused.
- Keep new weapon acquisitions from overwriting a full ring; fill free slots
  across both rings instead.

### Combat, XP and enemy behavior

- Correct excessive amoeboid XP through the common accepted-damage conversion,
  respecting the configured XP rate, health scaling and reward multiplier once.
  This includes damaging weapons, streams, explosions, swallowing, morphing,
  Taunter and Decoy receipts. Split descendants award no weapon or Nanotech XP;
  independently placed small/medium/large stages retain 100/200/300 HP.
- Correct captured/fired Suck Cannon crate presentation: retain the original
  crate pose, scale, contents and visibility, rebuild its bounds at launch, and
  avoid creature-only fire/bounce animations on crate models.
- Keep Veldin's shared electrical-beam visual manager on the native clock while
  enemy AI uses its configured speed. Extra manager updates must not delete the
  beam before it is drawn.
- Add a pure-attraction Taunter mode for challenges such as Orxon's force field.
  Optional damage, stun and launch settings live in its experimental group;
  per-grade R1 limits control access to the offensive mode. Neither mode grants
  Nanotech XP.
- Restore localized V6–V8 names and pause-menu XP for weapons without native
  Gold-name rows, including Drone Device, Taunter, Walloper, Visibomb and R.Y.N.O.
- Correct Walloper's equipped hand visibility and the affected Batalia/Veldin II
  skill-point paths.

### Randomizer, shops and pickups

- Add buy-all ammunition to the PDA, using the same owned-weapon capacities,
  prices and sufficient-bolts requirement as the vendor option.
- Add grey Bolt Packs to unused Randomizer All locations, with configurable
  standard-bolt value and localized collection text.
- Add six separate extra-location switches for **new All seeds**. Existing saves
  retain their saved selection. With all six Off, Hoven's extra location remains
  active so the complete reward pool, including all 40 Gold Bolts, is retained.
- Defer purchased gadget instruction videos until the shop has closed. Skipping
  or completing a video must return control without repeatedly reopening/closing
  the vendor. Multiple queued acquisitions are presented separately.
- Preserve original NPC prices regardless of the randomized reward. The Novalis
  plumber displays and charges 500 bolts. The requested exception is the Rilgar
  R.Y.N.O. salesman in Randomizer All, whose offer costs 15,000 standard bolts.
- Preserve all previously integrated source-claim, persistent shop, mission/race
  handoff, grind-rail pickup and early-equipment progression fixes.

### Optional gadget combat

These features are configurable and do not replace original story interactions:
native Swingshot targets, Trespasser pads and Hydrodisplacer water pads keep priority.

- **Swingshot:** pull ordinary enemies and optionally grapple walls, ceilings or
  crates. Use the real animated muzzle for the cable and block voluntary movement
  only while hooked. Release recovery covers native jump/fall/hover states and
  final deferred item updates, maintaining a valid body pose and Clank attachment.
- **Trespasser:** capture requires physical contact with a living eligible enemy.
  Hold it at a fixed compensated rotation centre, with half a game unit of extra
  clearance beyond the size-based tip offset. Suppress its body collision while
  held, restore the original state on living release, and preserve normal death,
  accepted damage and XP. The motor plays only while an enemy is captured.
- **Hydrodisplacer / Freezer:** launch area-freezing ice, with configurable ammo,
  rate, freeze area/duration and colors. Frozen enemies have blue/white condensation;
  existing hostile projectiles keep moving. Its weapon-style HUD shows ammunition
  and timed recharge, becomes yellow at full capacity, and does not fire merely
  from the button used to equip it. Detonations use the native Hoven freeze sound.
- **Hologuise:** configurable movement and animation speed while disguised.
- Preserve continuous Lavagun flow through enemy contact and the existing
  configurable weapon experiments, damage clocks and per-instance hit identity.

### Rendering, loading and packaging

- Correct the affected water-strip presentation and reduce the extra underwater
  fog applied to Pokitaru's layered ocean surface. Preserve normal world fog,
  swimming and underwater tint; visual behavior can still depend on the GPU.
- Prepare Thruster-Pack flame recognition on the loader worker instead of opening
  overlays at first use. No active-level global is changed to warm the cache.
- Include the subsequent grapple pose, contact, collision, capture/audio and
  Freezer presentation refinements through the tested v140 source.
- Keep the approved default configuration and supplied launcher icon. Ship one
  clearly named Windows asset; GitHub provides the matching tagged source.
  Verification information is inside the package/Actions, not extra release assets.

## Install or update

1. Extract the **entire Windows ZIP** into a writable folder.
2. Run `ReRAC_Weapon_Evolution.exe`.
3. Select your extracted game data if automatic discovery does not find it.
   That directory must contain `toc.bin` and `extract-info.json`.
4. Use the included modified `runtime/rerac.exe`, then **Save and launch**.
   A named preset is optional. Do not import this ZIP into the official launcher.

Back up your existing installation and saves before updating. Import/copy personal
profiles and presets if desired; the included `weapons.ini` is the approved default.
If old settings remember an absolute runtime path, select this package's runtime.
Do not copy an older executable over the new one. Existing compatible saves,
XP, control bindings, randomizer seeds and placements remain readable; updating
does not silently reroll a run. New-seed options apply to new games only.

## Randomizer testing and blocked runs

**Randomizer All is still being tested and may generate seeds that cannot be
completed.** Automated route checks do not prove every physical path or mission
script. If a run is blocked, save and close the game, then ZIP the entire
randomizer memory-card folder, including native saves and matching `.wev`
companions. The default Windows path is:

```text
%APPDATA%\rerac\memcard\randomizer\
```

Keep the region-specific card folder and companion files together. Use the actual
`saves: memory card folder ...` path printed at startup if your installation
uses a custom save root. Share the ZIP in a repository issue with the mod/runtime
version, current planet, unlocked equipment and routes already checked.
Community reports help improve access rules and seed generation.
