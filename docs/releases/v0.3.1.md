# Weapon Evolution 0.3.1

For **ReRAC 0.3.4-alpha**. The Windows x64 player ZIP includes modified runtime
patch **0.1.6.49**, configuration capability **48**, and English launcher
**0.10.0**. Game data is not included. TomRus47 authored this independent mod,
not ReRAC or the original game; credit belongs to their respective developers.

## Fixes since public v0.3

- Fix a reproduced death-reload crash caused by stale electrical-effect
  callbacks after object-table compaction. Clear old callback, companion,
  reaction and shared arc references before respawn.
- Improve Pyrocitor/Tesla accepted damage and XP across enemy-specific paths.
  Blaster/Pyrocitor/Tesla reactions use a three-second cooldown while accepted
  damage continues. Prevent repeated push on Eudora blade flyers.
- Give real-HP amoeboids 300/200/100 HP by size, split only at zero, and credit
  actual health loss without skipping smaller generations.
- Detonate Devastator/R.Y.N.O. missiles at maximum range with damaging blasts;
  correct R.Y.N.O. terminal damage, including tanks.
- Stabilize steep/downward locked-camera aim and apply directional leg poses
  to replacement boots.
- Clear upgrade notices on death/reload; release the experimental R.Y.N.O.
  firing stance without allowing cooldown bypass.
- Restore flame-mine landing/contact and custom launcher icon handling.
- Remove temporary audio probes. Base-runtime rain/taxi audio is not claimed
  fixed by this release.

## Additions and changes

- XP bars immediately below the pause Weapons page's selected name panel.
- Up to ten ordered, size-aware Drone Device drones.
- Editable cluster bombs, triple flames, held Walloper lunges, Suck Cannon crate
  ammunition and a second native Tesla chain.
- R.Y.N.O. continuous missiles or a 35-pellet 7x5 shotgun with independent
  spread axes, an unaffected center and distinct origins at zero spread.
- Independent rotating flame-cross mines, Taunter stun launch distance, and
  Drone Device Sand Mouse companion behavior shared with native dens.
- Experimental settings grouped after all standard fields per grade, lossless
  profile migration, refreshed English developer and configuration documents.

## Installation

Download the **Windows x64 player ZIP**, extract it into a writable folder and
open `ReRAC_Weapon_Evolution.exe`. Keep `runtime/`, shaders, configuration and
launcher together. Players do not need Python, Rust or earlier patches. Select
your extracted ReRAC data if automatic detection does not find it.

GitHub's automatic **Source code** downloads contain no executables. Back up
existing INIs/presets before updating and import personal settings into the
new launcher. A named preset is optional; the default workflow reads
`weapons.ini`. Saves retain progression; existing drone counts are not raised
automatically. The supplied default reflects the latest provided v48 profile.

## Validation and remaining checks

The Oltanis stale-callback fixture produces the original panic before the fix
and passes after it. Automated results are in the repository's
`docs/mod/VERIFICATION.md`; the Windows workflow builds and smoke-tests both
packaged executables and emits checksums.

**Keep this release as a draft until gameplay checks are complete.** Repeated
death reloads at the reported Oltanis checkpoint, Quartu electrical effects and
companion/drone behavior after respawn still need checks with extracted data.
Tests and executable smoke tests do not establish visual behavior or prove
that every reported crash has been eliminated.
