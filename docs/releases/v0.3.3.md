# Weapon Evolution 0.3.3

Unofficial mod for **ReRAC 0.3.4-alpha**. Gameplay patch **0.1.6.51**,
configuration capability **51**, English launcher **0.11.0**.

## Changes

- Silence secondary Tesla-beam lock-on audio; retain one weapon hum and the existing damage/XP behavior.
- Add per-grade Gold texture controls for Visibomb, Taunter, Walloper and R.Y.N.O.; every evolving weapon now exposes appearance independently of Gold mechanics.
- Add OmniWrench Gold appearance in Global Settings, without adding XP grades.
- Add an opt-in **experimental ammo-unlock mode** in Global Settings: ammo unlocks a weapon, running out locks it, and every unlock restores its quick-select icon.
- Unlock Taunter, Suck Cannon and Morph-o-Ray permanently at 25,000 / 50,000 / 75,000 collected normal bolts. Walloper remains available immediately.
- Ammo crates drop one to four independent normal ammo packs. All ammo weapons can appear immediately, with common basic weapons and rare Visibomb/Decoy/R.Y.N.O. ammo.
- Gold Bolts improve crate pack-count probabilities linearly from 50/40/8/2% at zero to 25/25/25/25% at forty.
- Disable weapon/ammo shops, PDA purchases, Gold offers and the R.Y.N.O. seller only while that experimental mode is active.
- Include owned R.Y.N.O. ammo in ordinary randomized crate drops too, including the US disc's omitted vendor-list case.
- Save the mode's progress per slot and retain compatibility when reading previous XP companions.
- Include previous v50 shotgun, loading, respawn, camera and weapon fixes.

The mode is **off by default**. Existing damage, XP, colors, capacities and
per-weapon experiments are preserved. Gold purchases are not converted into
experimental upgrades. See the [mode documentation](https://github.com/TomRus47/rerac-weapon-evolution/blob/main/docs/mod/AMMO_UNLOCK_MODE.md)
for exact rarity, probabilities, save behavior and review steps.

## Package and update

Extract the complete Windows player ZIP and start `ReRAC_Weapon_Evolution.exe`.
Use the included **v51 `runtime/rerac.exe`**. Players need their own extracted
ReRAC game data; Python and Rust are not required.

Keep a backup, then copy personal `weapons.ini`, presets and launcher settings
into the new player folder. The new launcher fills only missing controls and
preserves existing values. If copied settings point to an old absolute runtime
path, select the new included runtime. Do not replace it with the old EXE.

The companion save format is version 2; older companions load and migrate.
After saving with v51, use v51 or newer to retain the new companion state.

The release also includes a source ZIP from the exact compiled commit,
a checksum for each ZIP and `release-build.json` with the binary identity.
Keep the release a **draft** until the in-game review is complete. Build/tests
cannot establish disc-specific asset coverage or visual/audio behavior.

TomRus47 authored Weapon Evolution only, not ReRAC or the original game.
Existing credits and licenses are retained. No disc assets or personal saves
are included in either download.
