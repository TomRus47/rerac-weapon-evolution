# Weapon Evolution 0.3

Independent mod for **ReRAC 0.3.4-alpha**. Gameplay patch **0.1.6.56**,
configuration capability **56**, launcher **0.16.0**.

## Changes since 0.2

- Upgrade the OmniWrench through five independent XP grades. Configure damage, throw range/speed, Gold appearance, optional moving attacks, top-left HUD visibility, Crate Breaker and additive bolt attraction for every grade.
- Add per-grade wrench hit-radius and horizontal knockback multipliers. Hit-radius tuning covers the full three-hit combo, aerial attacks, slam and thrown wrench. Preserve native animations, vertical reactions and enemy resistance.
- Place OmniWrench immediately after Global Settings. Group all four upgrade requirements in one XP progression panel for every weapon.
- Add launcher languages: English, Italian, French, German and Spanish, including localized weapon names, labels and help. Changing language preserves unsaved edits and selected presets.
- Use Off/On dropdowns consistently. Keep standard and experimental controls in separate frames with consistent field order and colors at the bottom of their respective frame.
- Add an independent maximum-ammo setting for every supported experimental weapon mode; preserve standard capacities when experiments are disabled.
- Add optional **Ammo-Survival Mode**: collecting ammunition unlocks weapons, running out locks them, and every unlock restores its quick-select icon. New games start with zero Bomb Glove ammunition in this mode.
- Configure ammunition drop weights and permanent normal-bolt unlock thresholds. Defaults: Taunter 10,000; Suck Cannon 25,000; Walloper 50,000; Morph-o-Ray 75,000. Weapon/ammunition shops are disabled only while this mode is active.
- Ammo crates drop one to four packs; Gold Bolts gradually improve pack-count probabilities. Include R.Y.N.O. ammunition in eligible ordinary randomized drops as well.
- Add Gold appearance controls for the remaining weapons, brighten grade icons, and silence the secondary Tesla-beam lock-on audio while retaining its damage behavior.
- Add an experimental Visibomb grenade launcher with configurable size, trajectory, damage, explosion effects and terrain-aware ground reticle. Ratchet keeps movement and camera control. Grenades fall beyond horizontal range, explode on contact including water, and disappear in death zones.
- Add configurable flame-mine size and rotation synchronized with the flames.
- Improve R.Y.N.O. shotgun projectile-core visibility under particle pressure while preserving physical projectile damage and range handling.
- Preserve previous independent damage/XP attribution, reaction-cooldown, respawn, loading, camera, HUD and weapon fixes.

Experimental modes remain optional. Existing profile values are preserved when
missing settings are added. Gold purchases are not converted into experimental
upgrade purchases.

## Download and play

Download **ReRAC_Weapon_Evolution_0.3_windows_x64.zip**, extract the complete
archive into a writable folder, then open **ReRAC_Weapon_Evolution.exe**.
Keep the included **runtime/rerac.exe**, configuration and launcher together.
Players do not need Python, Rust or previous mod patches.

Select your own extracted Ratchet & Clank game-data directory if automatic
discovery does not find it. It must contain `toc.bin` and `extract-info.json`.
No original game assets are included. Creating a named preset is optional:
with no preset selected, the launcher loads the current `weapons.ini`.

Back up saves, configuration and presets before updating. Copy personal profiles
into the new folder if desired, and select the newly included runtime if copied
settings point to an old absolute path. Save companions use **WEVO v3**: older
v1/v2 companions can be read, but keep backups before downgrading to an older
runtime that cannot read v3.

## Source and verification

**ReRAC_Weapon_Evolution_0.3_source.zip** contains the complete modified Rust
workspace, launcher, public default configuration, tests and developer docs
from the exact commit used to build the Windows package. It is the developer
download, not the ready-to-play package. Both ZIPs have SHA256 sidecars;
`release-build.json` records the compiled runtime and source identity.

The tested v56 source passed **1,013 Rust game-library tests** and **119 Python
tests** locally. The author approved publication after local testing. The
Windows release workflow additionally validates source integrity, runs tests,
builds the modified runtime and checks the packaged launcher before publishing.
Automated checks do not establish every disc-specific visual behavior.

**TomRus47 authored Weapon Evolution only**, not ReRAC or the original game.
Credit and existing licenses for the port and game remain with their respective
developers. No disc assets, personal paths, settings or saves are distributed.
