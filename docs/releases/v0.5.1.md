# Weapon Evolution 0.5.1 — ReRAC 0.3.8-alpha

Source synchronization of the two supplied, completed fixes. Runtime
**0.1.6.142**, configuration capability **97**, launcher **0.30.2**.

## Fixes since 0.5

- **Explosion damage and XP:** the experimental Trespasser's private marker
  collided with the native explosion flag. Bomb Glove, ordinary Mine Glove,
  guided Visibomb and exploding chickens could be classified as drill hits,
  altering damage conversion and weapon/Nanotech XP attribution. Use a separate
  marker and require the actual Trespasser source class and Ratchet ownership.
  Keep accepted-HP accounting and one hit per enemy per explosion.
- **Recalled-weapon HUD:** after accepted wrench XP, the wrench name/XP feedback
  could outlast a Circle/R2 recall and cover the recalled weapon's panel.
  A completed hand-item change now retires that feedback and fade tail.
  Empty draw gaps, fresh delayed thrown-wrench XP, eight-second timing,
  pause/death behavior and normal/NG+ XP caps retain their existing behavior.

No approved default values, balance, icon, launcher UI, save formats or saved
randomizer layouts change. Both fixes are included; v141 need not be installed
separately before v142. Technical details and regression coverage:
[v141](../mod/LOCAL_TEST_V141.md), [v142](../mod/LOCAL_TEST_V142.md).

## Source and existing release

The existing public release has been renamed **0.5.1** and has a Windows player
asset, but its tag is still **v0.5** at the earlier v140 source commit.
Updating `main` does not change GitHub's automatic ZIP/TAR.GZ for that tag.
Use the [current main source archive](https://github.com/TomRus47/rerac-weapon-evolution/archive/refs/heads/main.zip)
or check out `main` to build these fixes.

This integration changes source only. It creates no release or tag and does
not replace the existing Windows asset. The historical 0.5 release descriptor,
publication workflow and release notes retain their original scope.
The 0.5.1 candidate descriptor remains manual and unpublished.

See [source validation](../mod/SOURCE_SYNC_051.md) for current checks and the
limits of the supplied kit's earlier verification.
