# Weapon Evolution 0.4.1 — ReRAC 0.3.8-alpha

Independent mod for **ReRAC 0.3.8-alpha**. Gameplay **0.1.6.116**, configuration
capability **92**, standalone launcher **0.29.5**. This is an **unpublished draft**;
the published 0.4 release and earlier downloads remain unchanged.

TomRus47 creates Weapon Evolution only and is **not associated with the development
of ReRAC or the original Ratchet & Clank games**. No rights to the original games,
characters, trademarks or game assets are claimed. Rights remain with their
respective owners. Huge thanks to the ReRAC developers: their work on the port,
ongoing fixes and new features make mods like this possible. Upstream licenses
and third-party credits are retained.

## Changes since Weapon Evolution 0.4

### Runtime integration

- Integrate the official **0.3.7-to-0.3.8** delta: 53 changed paths across 25
  upstream commits, with per-file provenance in `mod/upstream_038.json`.
- Preserve existing progression, real-HP combat, experimental weapons, camera
  lock, saved shortcuts, live configuration and randomizer systems while merging
  the upstream fixes. See `docs/mod/RUNTIME_038.md` for integration boundaries.
- Include upstream Gold lighting/metal rendering, glove landing previews,
  platform/carrier behavior, Gemlik return-ship recovery, native chicken fixes,
  magnetic-surface wrench alignment, language persistence, aspect-ratio and
  connected-controller updates.

### Input, rewards and acquisition scenes

- Reject repeated moving Comet-Strike throws while the single wrench remains in
  flight. Spamming Square no longer re-enters the throw animation and voice;
  configured movement after throwing remains available.
- Use localized, item-neutral **“You found: <reward>”** notices for randomized
  weapons, gadgets, coordinates and other rewards in all five supported languages.
- Correct randomized NPC offer names and subtitles, including Pokitaru's
  Raritanium/Persuader exchange. Preserve prices and interaction conditions.
  Original recorded voice performances are not replaced or regenerated.
- Select available gadget-specific acquisition scenes instead of treating gadgets
  as Bomb Glove demos. Preserve one-shot jingles and restoration of previous music.
  Underwater collection keeps its no-cutscene policy.
- Restore the native Gold Bolt hold-up cutaway without an additional acquisition
  jingle. Keep its cosmetic actor scheduled while hidden or away from the camera,
  finish its animation/tail and restore control.
- Add completion safeguards for missing/stalled presentation resources and
  streamed weapon/gadget scenes, preventing permanent pickup poses.
- Preserve randomized Magneboots/Grindboots models and equipped feet across travel,
  without requiring manual re-equipping on the next planet.

### XP and the reward chain

- Separate placed amoeboid weapon XP from Nanotech XP. Placed small/medium/large
  actors retain their **100/200/300 weapon-XP budget**; Nanotech uses actual
  accepted HP loss converted by the configured XP rate, with encounter scaling
  and the active reward multiplier applied once.
- Split descendants award **no weapon or Nanotech XP**. Overkill, repeated hit
  callbacks, duplicate collision primitives and unsuccessful conversions cannot
  grant another target-life award. This covers affected damaging weapons,
  including the wrench, swallowing and morphing paths.
- Count successful normal/Gold Morph-o-Ray conversions as one defeated eligible
  enemy for the bolt/weapon-XP/Nanotech-XP chain. Failed or repeated conversions
  and the resulting chicken cannot count again.

### Compact Nanotech progression

- Draw at most **30 spheres**, centered in two rows of up to 15, while retaining
  native four/five/eight-HP layouts and expanded 50% size/spacing.
- Represent higher HP in layers: native blue **1–30**, purple **31–60**, red
  **61–90**, orange **91–120**, yellow **121–150**, green **151–180** and white
  **181–210**. These represent real integer HP, not an additional armor system.
- Limit usable health to **210 HP**. The launcher accepts a base-plus-XP ceiling
  of **4–206**. Premium adds one independent HP and Ultra adds three more.
  **Ordinary new games still start with four HP and zero Nanotech XP.**
- Add `nanotech_progression_max_health` with explicit semantics and migrate older
  XP-bonus-only settings without changing their effective balance. Older earned
  progress remains readable; lowering the cap does not erase it.
- Keep the disposable Veldin II health test separate from normal gameplay. Only
  its explicit test entry point starts at 210/210 HP with ordinary saves disabled.

### Launcher, defaults and build reliability

- Explain the health ceiling and Premium/Ultra reservation in English, Italian,
  French, German and Spanish. Retain preloaded pages and existing scrolling controls.
- Use the author's supplied **root `weapons.ini`** as the default. Every setting
  is preserved; only its stale compatibility comment changes to ReRAC 0.3.8-alpha.
  Named presets remain optional.
- Rebuild all local workspace packages when required, verify dependencies against
  the current checkout and select Cargo's actual reported executable. Prevent
  stale v114 outputs or mixed game/engine modules from entering v115/v116 builds.
- Keep runtime, shaders, GUI and required profile migrations in a backed-up
  installation transaction, with rollback on failure. Do not rewrite native saves.
- Provide matching Windows/source ZIPs, SHA256 checksums and an exact-commit report.
  Exclude disc data, personal paths, logs, sessions and saves from distribution.

## Randomizer testing — report blocked runs

**Randomizer All is still being tested and may generate seeds that cannot be
completed.** Automated route checks do not prove every physical path, script or
item dependency. Existing saves retain their seed and placements; updates do not
silently reshuffle an ongoing run.

If a run becomes blocked, save and close the game, then ZIP the **entire
randomizer memory-card folder**, including native saves and `.wev` companions.
On Windows the default is:

```text
%APPDATA%\rerac\memcard\randomizer\
```

Paste this path into File Explorer. Keep its region-specific card directory
(for example `BASCUS-97199RATCHET`) and companion files together. The actual folder
is printed at startup as `saves: memory card folder ...`; use that path if your
installation overrides the default. Weapons-only discovery saves use a separate
`golden_bolts_to_weapons` folder and are not Randomizer All saves.

Share the ZIP in a repository issue with the mod/runtime version, current planet,
unlocked equipment, routes already checked and a short explanation of the block.
Include the relevant profile/seed if available and remove unrelated personal files.
Community reports can help improve location gates, placements and seed generation
more effectively than repeated blind runs.

## Installation and updating

Extract the complete **Windows x64 player ZIP** and open
`ReRAC_Weapon_Evolution.exe`. Use the included modified `runtime/rerac.exe`.
Select extracted Ratchet & Clank data if automatic discovery does not find it;
the folder must contain `toc.bin` and `extract-info.json`. Original game data is
required and not included. Players do not need Python, Rust or earlier patches.
Do not import this standalone mod ZIP into the official ReRAC launcher.

Back up an existing installation before updating. Import personal profiles/presets
through the updated launcher so the older health cap is migrated. If remembered
settings point to an older runtime, select this package's `runtime/rerac.exe`;
do not copy an older executable over it. Native saves and WEVO companions retain
compatibility. Back up progress before testing older mod builds.

The **source ZIP** contains the complete exact source commit, build tools, tests,
configuration reference and implementation documentation. It is not the playable
package. See `README.md`, `docs/mod/DEVELOPER_GUIDE.md`, `docs/mod/RUNTIME_038.md`,
`docs/mod/NANOTECH_V116.md` and `docs/mod/VERIFICATION.md` for details.
