# Weapon Evolution 0.4.2 — ReRAC 0.3.8-alpha

**Unpublished draft.** Independent mod for **ReRAC 0.3.8-alpha**.
Gameplay **0.1.6.123**, configuration capability **93**, standalone launcher
**0.29.6**. This candidate integrates the complete local v117–v123 source.
The existing 0.4.1 release and downloads remain unchanged.

Weapon Evolution is an unofficial, independent mod by **TomRus47**, who develops
this mod only and is **not associated with the development of ReRAC or the
original Ratchet & Clank games**. No rights to the original games, characters,
trademarks or assets are claimed. They belong to their respective owners.
Many thanks to the ReRAC developers: their work on the port and its continuing
improvements make mods like this possible. Upstream licenses and credits remain
intact. Original game data is required and is not distributed with the mod.

## Changes since 0.4.1

### Randomized mission and NPC rewards

- Keep Pokitaru's final fighter-mission handoff available when the O2 Mask was
  already obtained elsewhere. Escort and fighter-mission requirements still
  apply; claiming the randomized source retires its offer normally.
- Keep the Blarg Station scientist's reward available with early Grindboots,
  and the Novalis coordinate offer available with early Aridia coordinates.
  Availability follows the original source's collection record, not possession
  of the unrelated item which normally came from that source.
- Correct both parts of hoverboard race completion: the hero's finish-line
  command and the host's prize dialogue. An early Hologuise no longer blocks
  Kalebo III's randomized prize; the equivalent Rilgar finish gate is corrected.
- Require a winning race and an unclaimed source. Repeat wins cannot grant
  another reward. Old finish counters do not silently grant prizes because
  those counters also include losses. Replay an affected race after updating.

### Persistent Gadgetron offers in Randomizer All

- Visiting a planet registers its original Gadgetron offer permanently. Its
  randomized reward remains available at normal vendors on other planets until
  purchased, even if the player left without opening the original shop.
- Preserve the reward's name/model, source price and single-claim behavior.
  Buying an offer removes it from every normal vendor.
- Finding a weapon in the world unlocks its ammunition without registering a
  separate sale or exposing an unvisited planet's offer. Unlocking coordinates
  alone does not count as visiting. NPC purchases remain separate and the PDA
  remains ammunition-only.
- Retain existing stock and source claims through save/load and NG+. These
  fixes do not regenerate seeds, move rewards or change the companion format.

### Input and enemy damage

- Allow R2 to activate equipped usable gadgets through the same contextual
  input path as Circle, while preserving menu and non-gameplay input handling.
- Preserve the firing Veldin II tank's original health tier in its shell's
  damage ownership. When health-class damage is enabled, direct and splash
  damage use the tank's original six-HP tier and the effective enemy-damage
  multiplier. Tank XP eligibility is unchanged.

### Pickups, combat and HUD

- Collect Gold Bolts and randomized rewards on grind rails without a cutaway
  interrupting movement. Preserve the native location's no-cutaway policy and
  the collection notification/sound.
- Rearm Morph-o-Ray eligibility for retained enemies only when native logic has
  restored a living, targetable life. Repeated callbacks for the previous life
  cannot award another transformation or XP.
- Keep locked combat aim horizontal inside Kalebo III's specific fixed-camera
  weapon-test rooms. The scripted camera remains in control; other rooms and
  ordinary locked-camera aiming retain their behavior.
- Replace Quartu's Bolt Grabber source with its actual randomized reward model
  and receipt presentation, instead of showing the original item's scene first.
- Show the wrench name and XP bar for eight seconds after accepted wrench XP,
  using the normal fade. Automatic hit feedback stops at V5 in a normal game
  and V8 in NG+; V5 in NG+ can still show it. Existing per-grade HUD suppression,
  swimming/death restrictions and scripted HUD hiding remain respected.

### Enemy tracking and progression gates

- Add **Enemy burst tracking** to Global Settings, initially **Off**, with help
  text in English, Italian, French, German and Spanish and live-apply support.
  Supported direct-shot burst enemies can aim each newly fired shot at their
  current target. Shots already in flight retain their native trajectories.
- Extend that option to Novalis robot shooters: turn during the firing state
  and update each emitted glob's aim instead of locking the whole volley to
  Ratchet's former position. Preserve native timing, shot count and damage.
- Preserve boss attack patterns, scripted destruction shots and the Hoven
  mounted-turret mission's native aiming behavior.
- Correct the affected Blarg ground-flame enemies' waiting/wake perception and
  Taunter alert handling, while preserving their authored entrance paths.
- In Randomizer All, lower only Orxon's identified Clank shortcut when the O2
  Mask is already owned and Clank-side checks remain pending. Keep it below
  until boarded, then resume native carrying behavior. The rest of Clank's
  route, gates and mission completion still apply.
- Restore Oltanis' statue event in NG+ when the Morph-o-Ray source remains
  claimed from the previous run. The other route prerequisites still apply;
  retained rewards are not respawned and inventory is not manufactured.

### Source and build integration

- Reconcile the complete, inventoried v123 workspace with main so the release
  retains all preceding local fixes and can be built from one source commit.
- Keep source-identity checks tied to the prepared development descriptor and
  use Cargo's reported executable. Retain scoped Rust compiler recovery for

- Include implementation notes and regression coverage for reward handoffs,

## Compatibility and testing

The runtime base remains **ReRAC 0.3.8-alpha**. Existing personal configurations,
presets, saves, seeds and reward placements remain compatible. The approved
default retains all 2,592 previous settings and adds only the neutral
enemy_burst_tracking = false option. No new balance profile is substituted.

**Randomizer All is still being tested and may generate seeds which cannot be
completed.** Code-level route checks do not prove every physical path or mission
script. To report a blocked run, ZIP the entire randomizer memory-card folder,
including native saves and matching `.wev` companions. The default Windows path is:

```text
%APPDATA%\rerac\memcard\randomizer\
```

Use the actual `saves: memory card folder ...` path printed at startup if your
installation overrides it. Keep the region-specific card folder and companions
together. Share the ZIP in a repository issue with your mod/runtime version,
current planet, equipment and routes checked. Community reports help identify
missing mission gates and improve generation without repeatedly guessing.

## Installation and updating

Extract the complete Windows x64 player ZIP and run ReRAC_Weapon_Evolution.exe.
Use its included modified runtime/rerac.exe and select your extracted game data
if needed; the folder must contain toc.bin and extract-info.json. Players do
not need Python, Rust or earlier patch ZIPs. Game data is not included.

Back up the existing player folder before updating. Keep personal profiles and
presets, then select the new package's runtime if saved settings still reference
the old executable. Do not replace the new runtime with an earlier one. Existing
randomizer saves keep their exact layouts; no new game is required for these
handoff, shop or race fixes. Replay a previously affected race to claim its prize.

The separate source ZIP contains the exact tracked release commit, launcher,
build tools, tests and documentation. It is not the playable package. See
README.md and docs/mod/DEVELOPER_GUIDE.md for build and implementation guidance.
