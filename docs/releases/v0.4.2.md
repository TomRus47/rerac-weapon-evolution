## Changes since 0.4.1

### Randomized mission and NPC rewards

- Keep Pokitaru's final fighter-mission handoff available when the O2 Mask was
  already obtained elsewhere. Escort and fighter-mission requirements still
  apply; claiming the randomized source retires its offer normally.
- Keep the Blarg Station scientist's reward available with early Grindboots,
  and the Novalis coordinate offer available with early Aridia coordinates.
  Availability follows the original source's collection record, not possession
  of the unrelated item which normally came from that source.
- Correct both parts of hoverboard race completion: the hero's finish-line
  command and the host's prize dialogue. An early Hologuise no longer blocks
  Kalebo III's randomized prize; the equivalent Rilgar finish gate is corrected.
- Require a winning race and an unclaimed source. Repeat wins cannot grant
  another reward. Old finish counters do not silently grant prizes because
  those counters also include losses. Replay an affected race after updating.

### Persistent Gadgetron offers in Randomizer All

- Visiting a planet registers its original Gadgetron offer permanently. Its
  randomized reward remains available at normal vendors on other planets until
  purchased, even if the player left without opening the original shop.
- Preserve the reward's name/model, source price and single-claim behavior.
  Buying an offer removes it from every normal vendor.
- Finding a weapon in the world unlocks its ammunition without registering a
  separate sale or exposing an unvisited planet's offer. Unlocking coordinates
  alone does not count as visiting. NPC purchases remain separate and the PDA
  remains ammunition-only.
- Retain existing stock and source claims through save/load and NG+. These
  fixes do not regenerate seeds, move rewards or change the companion format.

### Input and enemy damage

- Allow R2 to activate equipped usable gadgets through the same contextual
  input path as Circle, while preserving menu and non-gameplay input handling.
- Preserve the firing Veldin II tank's original health tier in its shell's
  damage ownership. When health-class damage is enabled, direct and splash
  damage use the tank's original six-HP tier and the effective enemy-damage
  multiplier. Tank XP eligibility is unchanged.

### Remaining local changes to reconcile before packaging

The following changes were developed in local v117–v123 kits. The complete
prepared source is required before they can all be represented by one exact
release commit; this list is not a claim that they are already in this checkout.

- Preserve the no-cutscene pickup policy on grind rails; refresh Morph-o-Ray
  handling for repeated/spawned enemies; correct locked aim in Kalebo III's
  fixed-camera weapon-test rooms and the randomized Quartu Bolt Grabber display.
- Provide optional enemy burst tracking, including Novalis shooters updating
  their aim between shots while preserving native volley timing.
- Show wrench XP feedback for accepted gains with its fade and grade-cap rules.
- Lower Orxon's specific Clank shortcut when Randomizer All starts that section
  with the O2 Mask already owned, without skipping the rest of Clank's route.
- Preserve Oltanis' statue event when its Morph-o-Ray check was collected in the
  source run and remains claimed in NG+, while still requiring the other routes.
- Improve the affected Blarg flame-wave enemies' perception/Taunter behavior.
- Retain private Rust recovery and actual-executable verification for local
  Windows kits. Restore console streams before closing installer logs so a
  successful update does not report a false failure at interpreter shutdown.

## Compatibility and testing

The runtime base remains **ReRAC 0.3.8-alpha**. Existing personal configurations,
presets, saves, seeds and reward placements must be retained. The approved 0.4.1
default remains the baseline until the complete local source is reconciled;
no new balance profile has been supplied for this release.

**Randomizer All is still being tested and may generate seeds which cannot be
completed.** Code-level route checks do not prove every physical path or mission
script. To report a blocked run, ZIP the entire randomizer memory-card folder,
including native saves and matching `.wev` companions. The default Windows path is:

```text
%APPDATA%\rerac\memcard\randomizer\
```

Use the actual `saves: memory card folder ...` path printed at startup if your
installation overrides it. Keep the region-specific card folder and companions
together. Share the ZIP in a repository issue with your mod/runtime version,
current planet, equipment and routes checked. Community reports help identify
missing mission gates and improve generation without repeatedly guessing.

Final Windows build results and exact package identities belong to the eventual
release commit's Actions run and `release-build.json`. No completed 0.4.2 Windows
build or in-game verification is claimed by this preparation note.
