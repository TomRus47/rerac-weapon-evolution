# Configuration reference

Generated by `python tools/mod/generate_config_reference.py` from `launcher/weapons.default.ini`, `launcher/schema.py` and the launcher validator. The default has 1168 entries.

This reference describes public player fields and the launcher's accepted types/bounds. The Rust parser and consuming hook must also be maintained when adding a field; the runtime can impose additional context-specific limits. `default` is accepted only where implemented, such as colors and native-range sentinels. The internal real-HP session marker is intentionally absent from the public profile.

Tick intervals use the 60 Hz simulation, not rendering FPS. Distances/multipliers retain the units and native fallback of their consuming weapon hook. HP/s applies to stream contact for Pyrocitor/Tesla and to the separate offensive aura for Taunter. XP thresholds are per transition. Inventory IDs are fixed; in-game names are localized by the game.

See [Developer guide](DEVELOPER_GUIDE.md) for extension recipes and the damage/XP contracts.
